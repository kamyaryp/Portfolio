# Kamyar Yazdanpanah — Portfolio

Personal portfolio of Kamyar Yazdanpanah, Senior Product Designer.

**Live:** https://kamyaryp.github.io/Portfolio/

## Structure

| Path | What it is |
| --- | --- |
| `index.html` | The site: styles and scripts inline. Pages are hash routes: `#work` (home), `#about`, `#contact`, `#djoid` |
| `portrait.js` | `<pixel-portrait>` component: loading intro and top bar avatar |
| `fonts/` | Geist and Geist Mono, self-hosted (SIL Open Font License) |
| `work/djoid/` | Djoid case study images |

No build step and no dependencies. Open `index.html` locally, or serve the folder as a static site.
